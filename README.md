# EasyBite 🍴  
_A personalized restaurant recommendation app powered by machine learning._

---

## 📖 Description  
EasyBite is a mobile application that provides tailored restaurant suggestions based on user preferences, using a content-based recommendation system. Users can swipe through restaurant options and receive recommendations influenced by features like cuisine type, price range, and food tags.  

---

## 🚀 Features  
- **Personalized Recommendations**: Tailored to user preferences with explicit restaurant attributes.  
- **Interactive UI**: Swiping functionality for a seamless user experience.  
- **Scalable Backend**: Built with Flask and MongoDB for efficient data handling.  
- **Machine Learning-Powered**: TensorFlow-based recommendation engine.

---

## 🛠️ Technologies  
- **Frontend**: React Native  
- **Backend**: Flask, MongoDB  
- **Machine Learning**: TensorFlow, Python  
- **Hosting**: In progress!
